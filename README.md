# ITC India Website (Next.js)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — start production server

Static HTML reference files live under `legacy-pages/` and `index.html` (not used by Next.js).
